# SentinelGrid development roadmap

**Development Status: In Progress**

This is a phased plan for proposed development.

### Phase 1: Foundation

Build a local replay harness with synthetic Security Hub and CloudTrail events, schemas, and deterministic case grouping.

### Phase 2: Core system

Add AWS ingestion, durable evidence storage, enrichment, replay, and an analyst case API.

### Phase 3: Evaluation

Add evidence-cited summaries and an analyst review interface; measure grouping and triage against a baseline.

### Phase 4: Hardening

Harden IAM, retention, observability, cost controls, and deployment documentation.
